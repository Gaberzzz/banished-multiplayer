**Banished Multiplayer now runs on Linux** through Proton or Wine. Windows players get a few fixes too.

**Everyone in a game needs this version.** A host turns away players whose DLL is different, so players on 0.9.7
must update before they can join a 0.9.8 game, and the other way round.

### Install

- **Windows:** unpack the zip and double-click `Install.bat`.
- **Linux:** unpack the zip and run `bash BanishedMultiplayer/install.sh`. Then set the launch option it shows
  (`WINEDLLOVERRIDES="dinput8=n,b" %command%`) and choose DirectX 11 in Banished's video options. There's a full Fedora
  guide in the [README](https://github.com/Gaberzzz/banished-multiplayer#linux-fedora).

`bmpShare.pkm` hasn't changed since 0.9.7. If you have it from the Steam Workshop or banishedinfo.com, you only need
the new `dinput8.dll`, and `Install.bat` / `install.sh` installs only that.

### New

- **Linux support (Proton / Wine).** The DLL works the same way under Wine. The new `install.sh` finds Banished in
  native, Flatpak and Snap Steam libraries and in Heroic, Lutris, Bottles and Wine folders, including GOG installs.
  `install.sh --uninstall` removes the mod again.
- The log and bug reports show the Wine version when the game runs under Wine.

### Fixes

- **Bug reports under Wine** are saved in the Banished folder, and the status line shows its Linux path. Before, they
  went to a Desktop folder hidden inside the Wine prefix.
- **Bug reports remove more personal details:** Linux user names in `/home/<name>`, `/media/<name>` and
  `/run/media/<name>` paths, and user names that contain non-ASCII letters.
- A very long bug-report header could close the game. Fixed.
- On Windows, a report no longer says "saved on your Desktop" when the Desktop folder couldn't be found.
- **Missing or wrong `bmpShare.pkm`:** under Wine the warning shows the WinData folder's Linux path, and the button
  that opened Wine's file browser is gone.
- **Installer (`Install.bat`):** you can unpack the zip straight into the Banished folder and install from there.
  Uninstalling no longer overwrites a `dinput8.dll` that another mod put there after this one.
